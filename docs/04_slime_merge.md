# くっつきスライム（2048風パズル）

対応 issue: #5

## 概要

4×4グリッドで同じ数値のスライムを合体させながら「キングスライム（2048）」を目指す2048風パズルゲーム。スワイプ/矢印キーで操作し、スコアのハイスコアを localStorage に保存する。

## 実装内容

### ファイル構成

```
games/slime-merge/
├── index.html          — タイトル・ゲーム画面（ゲームオーバー・勝利はオーバーレイ）
├── css/
│   └── style.css       — タイルカラーテーブル・出現/合体アニメーション
└── js/
    ├── sound.js        — Web Audio API 効果音（5種）
    ├── game.js         — 移動ロジック（slide/transpose/reverse）・スポーン・判定
    └── main.js         — DOM レンダリング・タッチ/キーボード入力・画面管理
```

## 使い方

- スワイプ（上下左右）または矢印キーでスライムを動かす
- 同じ数値のスライム同士がぶつかると合体して数値が2倍になる
- 合体で生まれた数値がスコアに加算される
- **2048** に達したらキングスライム誕生！（ゲームは継続可能）
- 空マスがなく合体できなくなったらゲームオーバー

| 数値 | スライム名 | 色 |
|---|---|---|
| 2〜4 | ちびスライム | ピンク/黄緑 |
| 8〜16 | スライム | 水色/橙 |
| 32〜64 | でかスライム | 紫/赤 |
| 128〜256 | ぬりかべ | 青/緑 |
| 512 | ジェリー | 金 |
| 1024 | スーパースライム | 虹 |
| 2048 | キングスライム 👑 | 白金（輝く） |

## 技術的な補足

- 移動ロジック: 全方向を「左スライド」に統一し、`transpose`/`reverseRows` で回転して処理
- 合体フラグ (`merged`) で1スワイプにつき各タイルは最大1回のみ合体
- 盤面変化なし（移動できなかった）場合は新スライムをスポーンしない
- ゲームオーバー判定: 空マス0かつ隣接同値ペアなし
- 2048達成後は `wonShown` フラグで再表示を防ぎ、ゲームを継続できる
- 入力ロック (`locked`) でアニメーション中の連続入力を防止（120ms）
- ボードサイズは画面サイズから動的計算し、`resize` イベントに追従
- ローカル確認: `python3 -m http.server 8000` → http://localhost:8000/games/slime-merge/
