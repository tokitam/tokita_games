# ゲーム案ネタ出し（10本）

作成日: 2026-08-08

## 前提条件

- ウェブブラウザで完結する
- スマホからアクセスしても快適に遊べる
- 1つ1つをゲームとして作りきる
- まずは定番ものを作成する
- サーバ側は React/Vue なしで、HTML / JS / CSS / 画像 / 音声ファイルを置くだけの静的構成
- ポップな見た目・世界観にする

## ゲーム案一覧

### 1. ポイポイブロック（テトリス風落ちものパズル）

落ちてくるブロックを揃えて消す定番落ちものパズル。スマホはスワイプ移動・タップ回転。丸っこいブロックとポコポコ効果音でポップに。

### 2. モグポン！（もぐらたたき）

画面の穴からひょこっと出るキャラをタップするもぐらたたき。時間制限30秒でスコアアタック。タッチ操作と最高に相性が良く、最初の1本に最適。

### 3. ペアペアどうぶつ（神経衰弱）

どうぶつカードをめくってペアを当てる定番記憶ゲーム。3×4〜6×6の難易度選択。実装が軽く、絵柄で世界観を作りやすい。

### 4. くっつきスライム（2048風パズル）

スワイプで同じ数字（同じ色のスライム）を合体させていくパズル。スマホ操作の気持ちよさが抜群で、リトライ性が高い。

### 5. カラフルクラッシュ（ブロック崩し）

指でパドルを左右にドラッグしてボールを跳ね返す定番アクション。アイテム（ボール増殖・パドル拡大）を入れると一気にゲームらしくなる。

### 6. ぴょんぴょんバード（フラッピー系）

タップでふわっと浮かぶ鳥を操作して土管の隙間を抜ける。ワンボタンで操作説明不要、スコアの悔しさで何度も遊べる。

### 7. フルーツぽとん（スイカゲーム風物理パズル）

上からフルーツを落として、同じ同士をくっつけて大きく進化させる物理パズル。物理演算は軽量ライブラリ（Matter.js をファイル同梱）でOK。今どき感と定番感の両立。

### 8. ポンポンビート（リズムタップ）

流れてくるマーカーをタイミングよくタップする音ゲー。音声ファイルを置くだけで成立し、静的ホスティング条件と好相性。判定は Perfect/Good/Miss の3段階。

### 9. どこちがう？（間違い探し）

左右2枚のポップなイラストから違いをタップで探す。画像ファイル+座標データ（JSON）だけで量産でき、ステージ追加が容易。

### 10. いろタッチ（早押し反射ゲーム）

「あか！」と指示された色のパネルを素早くタップ。たまに文字と色が食い違うひっかけ（ストループ効果）あり。1プレイ20秒、ハイスコアは localStorage 保存で繰り返し遊べる。

## 補足

- 全案とも **HTML + CSS + JS + 画像/音声を置くだけ** で動く。ビルド不要、React/Vue 不要。
- 案7の物理演算のみ Matter.js のファイルを1個同梱する形。
- スコアやハイスコアは localStorage に保存すればサーバ不要でランキング気分が出せる。
