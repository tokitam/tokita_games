# モグポン！（もぐらたたき）

対応 issue: #3

## 概要

30秒の制限時間内に、穴からひょこっと出るキャラクターをタップして叩くもぐらたたきゲーム。通常モグ・レアモグ・ハズレの3種類が登場し、時間経過で難易度が上がる。

## 実装内容

### ファイル構成

```
games/mogpon/
├── index.html          — タイトル・ゲーム・リザルトの3画面
├── css/
│   └── style.css       — レスポンシブ対応・ポップなデザイン
└── js/
    ├── sound.js        — Web Audio API 効果音（6種）
    ├── game.js         — ゲームロジック（タイマー・出没スケジューリング・スコア）
    └── main.js         — 画面遷移・DOM 操作・イベント登録
```

## 使い方

- 穴から出てくるキャラをタップ/クリックで叩く
- 🐹 通常モグ: +1点（出現率 70%）
- ✨🐹 レアモグ: +3点（出現率 20%、短時間）
- 💀 ハズレ: -1点（出現率 10%）
- 残り3秒でカウントダウン音が鳴る
- ハイスコアは自動保存

## 技術的な補足

- DOM ベース実装（Canvas 不使用）。キャラは絵文字で画像ファイル不要
- キャラ出没は CSS `translateY` アニメーションでひょこっと演出
- フェーズ制: 0〜10秒（最大1匹）→ 10〜20秒（最大2匹）→ 20〜30秒（最大3匹）
- `touch-action: manipulation` でスマホの300ms遅延を回避
- ゲーム終了時に全タイマーを破棄（`clearTimeout` / `clearInterval`）
- ローカル確認: `python3 -m http.server 8000` → http://localhost:8000/games/mogpon/
