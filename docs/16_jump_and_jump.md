# ジャンプとジャンプ

## 概要
BabylonJS を使った3Dエンドレスジャンプゲーム（Doodle Jump の3D版）。自動でバウンドし続けるキャラクターを左右移動で操作し、らせん状に続く足場を登って高さスコアを競う。

## 実装内容
- `games/jump-and-jump/index.html` — タイトル・ゲーム・ゲームオーバーのSPA
- `games/jump-and-jump/css/style.css` — 縦型・空のグラデーション背景
- `games/jump-and-jump/js/sound.js` — Web Audio API でジャンプ・スプリング・ゲームオーバー効果音を合成
- `games/jump-and-jump/js/game.js` — キャラクター物理・足場生成・リサイクル・スコア・背景遷移
- `games/jump-and-jump/js/main.js` — BabylonJSシーン・カメラ・入力・UI

## 使い方
1. タイトル画面をタップまたはスタートボタンで開始
2. 画面の左半分を押している間→左移動、右半分→右移動（押しっぱなし対応）
3. 足場を踏み外して画面下に落ちるとゲームオーバー

## 技術的な補足
- キャラクター物理: 自前実装（BabylonJS物理エンジン不使用）
  - 毎フレーム `vy -= GRAVITY(0.012)`、着地時 `vy = JUMP_VY(0.32)`
  - スプリング足場は `vy = 0.32 * 2.2`
  - X軸ラップアラウンド（±4ユニット超えで反対側へ）
- 足場生成: 常に上方向15枚先まで生成。カメラより6ユニット下は足場プールへ返却（dispose なし）
- カメラ: `FreeCamera`。キャラがカメラの6割以上で追従（下には絶対戻らない）
- 背景色: 高度200ごとに「空色→夕焼け→星空」へグラデーション遷移（scene.clearColor）
- 足場種類: ノーマル（緑）・ムービング（青・高さ50〜）・クラウド（白・1回消え・高さ100〜）・スプリング（黄・8%固定）
- ハイスコアは `localStorage['jump-and-jump.highscore']` に保存
