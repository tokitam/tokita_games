# エアクラッシュ！（空中浮遊バトル）

## 概要

バニラ Canvas で実装した 2D 空中バトルゲーム。プレイヤー（青）が CPU（赤）と空中でぶつかり合い、壁に激突させることで HP を削る 1P vs AI ゲーム。

## 実装内容

- `games/air-crash/index.html` — Canvas・HUD・オーバーレイ HTML
- `games/air-crash/css/style.css` — 空をイメージした背景・オーバーレイ・タッチガイド
- `games/air-crash/js/sound.js` — Web Audio API によるSE（ジャンプ・壁ヒット・衝突・勝敗）
- `games/air-crash/js/game.js` — 物理演算・壁衝突・AABB キャラ衝突・CPU AI・描画
- `games/air-crash/js/main.js` — Canvas 初期化・入力管理・ゲームループ・画面遷移

## 使い方

- **PC**: `A` キー → 斜め左上に飛ぶ、`D` キー → 斜め右上に飛ぶ
- **スマホ**: 画面左半分タップ → 左上へ飛ぶ、画面右半分タップ → 右上へ飛ぶ
- 相手を壁にぶつけると相手の HP が減る（自分が壁に当たっても自分の HP が減る）
- HP が先に 0 になったほうが負け

## 技術的な補足

### 物理パラメータ
- 重力: 0.18、インパルス: 水平 ±3.2 / 垂直 -4.8
- 壁反射係数 BOUNCE=0.55 で減衰
- 無敵フレーム（INVINCIBLE=20）で同一壁ヒット連続ダメージを防止

### CPU AI
60〜85 フレームに 1 回判断。プレイヤーの方向にインパルスを与え、30% の確率でランダム外れを加えて難易度調整。

### キャラ衝突
AABB 重複判定。重複が水平 < 垂直なら水平方向に押し戻して vx を交換、逆なら垂直。HP ダメージなし（弾かれるだけ）。
