# ぽんぽんクッキング

## 概要
BabylonJS を使った3Dキャッチ＆クッキングゲーム。上から降ってくる食材をフライパンでキャッチし、注文どおりのレシピを完成させる。60秒でいくつ料理を完成できるかを競う。

## 実装内容
- `games/ponpon-cooking/index.html` — タイトル・ゲーム・リザルトの3画面SPA
- `games/ponpon-cooking/css/style.css` — キッチン風のカラフルなレイアウト。注文カードを上部に配置
- `games/ponpon-cooking/js/sound.js` — Web Audio API でキャッチ・完成・失敗・フィーバー効果音を合成
- `games/ponpon-cooking/js/recipes.js` — 食材・レシピ定義と材料一致判定ロジック
- `games/ponpon-cooking/js/game.js` — 落下・キャッチ判定・注文管理・フィーバー・状態管理
- `games/ponpon-cooking/js/main.js` — BabylonJSシーン（キッチン背景・フライパン・食材メッシュ）・入力・UI連携

## 使い方
1. スタートボタンをタップ
2. 左右ドラッグでフライパンを移動して食材をキャッチ
3. 注文と同じ食材が揃ったらフライパンをタップして炒める
4. 上フリックで食材を1個ずつ捨てられる
5. 60秒でゲーム終了

## 技術的な補足
- 食材の落下: `vy += 0.008` の緩い重力。同時最大8個まで
- キャッチ判定: 食材がフライパン高さに達した時、|食材x - パンx| < パン半径 で成功
- 注文一致: フライパン内の食材と注文材料の多重集合比較（順不同・過不足なしで一致）
- フィーバー: 3連続成功で10秒間、得点2倍・落下増加。フィーバーゲージ表示
- 邪魔アイテム（焦げた肉・ハエ）をキャッチするとフライパンの中身がリセット＆減点
- ハイスコアは `localStorage['ponpon-cooking.highscore']` に保存
