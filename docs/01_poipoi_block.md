# ぷにぷにテトリス風「ポイポイブロック」

対応 issue: #1

## 概要

7種類のテトロミノが落下する定番落ちものパズルを、静的ファイルのみ（HTML/CSS/JS）で実装した。スマホのタッチ操作とPC のキーボード操作の両方に対応し、丸っこいブロックとポコポコ効果音のポップな世界観に仕上げている。

## 実装内容

### ファイル構成

```
games/poipoi-block/
├── index.html          — 全画面（タイトル・ゲーム・ゲームオーバー）の HTML
├── css/
│   └── style.css       — スタイル。レスポンシブ対応・ポップなデザイン
└── js/
    ├── tetromino.js    — テトロミノ定義（形状・色・7-bagランダマイザー）
    ├── sound.js        — Web Audio API によるサウンド（mp3 不要の発振音）
    ├── game.js         — ゲームロジック（衝突判定・スコア・ライン消去・状態管理）
    ├── renderer.js     — Canvas 描画（フィールド・ゴースト・NEXT・フラッシュ）
    ├── input.js        — キーボード・タッチ入力の正規化
    └── main.js         — 画面遷移・ループ・各モジュールの配線
```

## 使い方

### スマホ

| 操作 | 内容 |
|---|---|
| タップ | 回転 |
| 左右スワイプ（1セル単位） | 左右移動 |
| 下スワイプ（短い） | ソフトドロップ |
| 下スワイプ（速い / 長い） | ハードドロップ |
| ⏸ボタン | ポーズ |

### PC

| キー | 内容 |
|---|---|
| ← → | 左右移動 |
| ↑ | 回転 |
| ↓ | ソフトドロップ |
| スペース | ハードドロップ |
| P | ポーズ |

## 技術的な補足

- **ランダマイザー**: 7-bag 方式（7種類を1セットでシャッフルして順番に出す）で偏りを防ぐ
- **ウォールキック**: 回転時に壁・床に当たる場合、±1〜±2 マスずらして再試行する簡易キック実装
- **Canvas DPI 対応**: `devicePixelRatio` を使いにじみを防止。Retina/高解像度ディスプレイ対応
- **roundRect ポリフィル**: Safari 15.3 以前に対応するため、`quadraticCurveTo` ベースの自前実装を renderer.js に内包
- **サウンド**: mp3 ファイルは不要。Web Audio API のオシレータで移動・回転・設置・ライン消去・レベルアップ・ゲームオーバーの6種を生成。iOS Safari の自動再生制限対策として、スタートボタンタップ（ユーザーのジェスチャー）時に AudioContext を初期化する
- **スコア**: 1列: 100 / 2列: 300 / 3列: 500 / 4列: 800 × レベル。ハイスコアは `localStorage` の `poipoi-block.highscore` に保存
- **フォールバック**: 効果音が利用できない環境でもゲーム本体は動作する
- **ローカル確認**:
  ```sh
  python3 -m http.server 8000
  # → http://localhost:8000/games/poipoi-block/
  ```
