# くるくるコマ対決

## 概要
BabylonJS を使った3Dコマバトル。円形の土俵上でプレイヤーとCPUのコマが回転しながらぶつかり合い、相手を場外に弾き飛ばすか先にスピンが止まった方の負け。3本先取のベストオブ5。

## 実装内容
- `games/koma-battle/index.html` — タイトル・ゲーム・リザルトの3画面SPA
- `games/koma-battle/css/style.css` — ポップな格闘ゲーム風レイアウト
- `games/koma-battle/js/sound.js` — カウントダウン・衝突・ノックアウト・スピンアウト効果音
- `games/koma-battle/js/game.js` — コマ物理（XZ平面2D円、弾性衝突）・CPUのAI・勝敗判定・状態機械
- `games/koma-battle/js/main.js` — BabylonJSシーン（土俵・コマ3Dメッシュ）・スワイプ入力・スコアUI

## 使い方
1. スタート画面から試合開始
2. カウントダウン中に上スワイプ（速さ=初期スピン量、方向=初速方向）
3. バトル中は1秒クールタイム後に再度スワイプで加速できる
4. 相手を場外に落とすかスピン0になった方が負け。3本先取で勝利

## 技術的な補足
- コマ物理は自前実装（物理エンジン不使用）。XZ平面の2D円として扱い、BabylonJSのメッシュはそれに追従
- 土俵中心からの微小引力で自然にコマが近づく設計
- CPU AI: 一定間隔でプレイヤー方向にダッシュ、ラウンドが進むと頻度・スピンが上昇
- ノックアウト時のスローモーション: engine.timeScale を 0.3 に設定し1秒後に戻す
- スコア表示: ハート形の丸を DOM で管理（取得本数分を強調表示）
- ハイスコア（最大連勝数）は `localStorage['koma-battle.maxwins']` に保存
