# まいごのひよこエスコート

## 概要

3D エスコートゲーム。街に散らばった迷子のひよこを見つけて後ろに連れ、光る巣まで送り届ける。同時に複数を届けるほどボーナス倍率が上がる。走るとはぐれリスクがある。

## 実装内容

| ファイル | 内容 |
|---|---|
| `games/hiyoko-escort/index.html` | タイトル・HUD・リザルト画面 |
| `games/hiyoko-escort/css/style.css` | スタイル（黄色テーマ） |
| `games/hiyoko-escort/js/main.js` | ゲームループ・HUD・ネスト方向インジケーター |
| `games/hiyoko-escort/js/chicks/Chick.js` | ひよこ 1 羽（プリミティブ組み立て + 状態管理） |
| `games/hiyoko-escort/js/chicks/ChickManager.js` | 配置・ブレッドクラム追従・はぐれ抽選・巣届け・ボーナス計算 |
| `games/hiyoko-escort/js/sound.js` | playPiyo / playJoin / playDeliver / playDrop |
| `games/index.html` | ゲーム一覧に 🐤 カード追加 |

## 使い方

1. タイトルで「きょうの街」か「ランダム」を選択
2. ピヨピヨ音を頼りにひよこを探す（近いほど間隔が短い）
3. 1.5m 以内に近づくと仲間に。後ろに列を作って追従する
4. HUD の巣インジケーター（黄色矢印）の方向に進む
5. 巣（中央の光るリング）の 3m 以内で連れているひよこが全員とどく
6. 8 羽全部届けたらクリア

## ゲームのポイント

| 項目 | 値 |
|---|---|
| ひよこ総数 | 8 羽 |
| 仲間になる距離 | 1.5m |
| 巣への届け距離 | 3m |
| 同時届けボーナス | 1 羽×1.0 / 2×1.2 / 4×1.5 / 8×2.0 |
| はぐれ確率 | 走り中・1 秒ごとに 12%（1 羽のみ） |
| 歩き中のはぐれ | なし |
| スコア基本 | 1 羽あたり 100pt × ボーナス倍率 |

## 技術的な補足

- **ブレッドクラム追従**: プレイヤーが 0.3m 移動するごとに位置を履歴に記録。i 番目のひよこは「i×2 ステップ古い」座標へ lerp 移動。経路探索不要で建物内に入らない
- **ひよこ外見**: `SphereGeometry`（体・頭）+ `ConeGeometry`（くちばし）+ `CylinderGeometry`（足）の組み立て。外部アセット不要
- **💧 マーク**: Canvas2D テクスチャを Sprite で頭上に表示。following になると非表示
- **巣**: 中央（0,0）に `RingGeometry` グロウリング + 光柱シリンダー + `PointLight`。パルスアニメーション付き
- **ピヨピヨ音**: 最近傍迷子ひよことの距離で間隔変化（最大 1.8s → 0.3s）
- **ミニマップ**: 迷子ひよこ（黄色ドット）+ 巣（黄星）+ プレイヤー三角を表示。following 中のひよこは非表示（プレイヤー後ろにいるため）
- `localStorage` キー: `hiyoko-escort.best` / `hiyoko-escort.best.daily.YYYY-MM-DD`
