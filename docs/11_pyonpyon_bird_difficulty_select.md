# ぴょんぴょんバード 難易度選択機能

## 概要
ぴょんぴょんバードのタイトル画面に「ちょうかんたん」「かんたん」「ふつう」「むずい」の4段階の難易度ボタンを追加した。ボタンをタップすると選択した難易度で即座にゲームが始まる。

## 実装内容
変更ファイル: `games/pyonpyon-bird/js/game.js`

- グローバル定数（`GRAVITY` 等）を `DIFFICULTIES` オブジェクトに統合し、難易度ごとのパラメータとして管理
- `difficulty` 変数でデフォルト難易度（`'ふつう'`）を保持
- `diffButtons` 配列でタイトル画面に描画したボタンの領域を保持し、タップ判定に利用
- `drawTitle()` にて4つの難易度ボタンを縦並びで描画。選択中ボタンは白背景＋太枠でハイライト
- `onTap(e)` を座標受け取り形式に変更し、`waiting` 状態でボタン領域内をタップした場合に難易度選択＆即ゲーム開始
- ハイスコアキーを難易度ごとに分離（`pyonpyon-bird.hs.{難易度名}`）

## 使い方
1. タイトル画面に4つの難易度ボタンが表示される
2. 好きな難易度ボタンをタップするとその難易度でゲームが始まる
3. ゲームオーバー後は同じ難易度でリトライできる（タイトルに戻ると再選択可能）
4. ベストスコアは難易度ごとに記録される

## 技術的な補足
- canvas のサイズ変更に対応するため、クリック座標は `getBoundingClientRect()` で取得した `rect` と `W / rect.width` スケールを使って変換する
- `diffButtons` は `drawTitle()` が毎フレーム呼ばれるたびに更新されるため、リサイズ後も正確なヒット判定が維持される
- `no10` ブランチ（PR #15）に追加コミットとして実装した
