# ペアペアどうぶつ（神経衰弱）

対応 issue: #4

## 概要

どうぶつの絵文字カードをめくってペアを当てる定番神経衰弱ゲーム。かんたん・ふつう・むずかしいの3難易度に対応し、ベスト手数を難易度ごとに localStorage に保存する。

## 実装内容

### ファイル構成

```
games/pair-animals/
├── index.html          — タイトル・ゲーム・クリアの3画面
├── css/
│   └── style.css       — CSS 3D フリップアニメーション・レスポンシブ対応
└── js/
    ├── sound.js        — Web Audio API 効果音（4種）
    ├── game.js         — カード生成・シャッフル・ペア判定・タイマー
    └── main.js         — 画面遷移・DOM 操作・ハイスコア管理
```

## 使い方

1. 難易度ボタンをタップして選択
2. カードをタップするとめくれる（CSS 3D フリップ）
3. 2枚めくってペアが一致: ✅ そのまま残る
4. 不一致: 1秒後に裏返す（シェイクアニメーション）
5. 全ペアを当てるとクリア

| 難易度 | グリッド | ペア数 | ★★★ |
|---|---|---|---|
| かんたん | 3×4 | 6 | 最低手数+2以内 |
| ふつう | 4×4 | 8 | 最低手数+2以内 |
| むずかしい | 6×6 | 18 | 最低手数+2以内 |

## 技術的な補足

- 絵文字18種（🐶〜🦜）を使用し、画像ファイル不要
- CSS `transform: rotateY()` + `backface-visibility: hidden` で3D フリップを実現
- `perspective: 1000px` をグリッドコンテナに設定（必須）
- ペア判定中は `locked` フラグで連打を防止
- 同一カード2回タップ時は無視（`flipped[0].id === id` チェック）
- 難易度ごとに `pair-animals.highscore.{easy|normal|hard}` をベスト手数として保存
- ローカル確認: `python3 -m http.server 8000` → http://localhost:8000/games/pair-animals/
