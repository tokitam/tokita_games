# 微妙に間違っている都道府県名のリストから正しい都道府県名を充てるゲーム

## 概要

都道府県名クイズ「Just都道府県名！」を新規作成した。3×3 の 9 枚のカードに都道府県名を表示し、1 枚だけある正しい表記をタップで当てる。全 5 問を正解するまでのタイムを競い、クリア後に X.com へタイムを投稿できる。

## 実装内容

### 追加ファイル

| ファイル | 内容 |
|---|---|
| `games/just-todofuken/index.html` | 3 画面（タイトル・ゲーム・リザルト）の HTML シェル |
| `games/just-todofuken/css/style.css` | ダークテーマのスタイル。3×3 グリッド、正解/不正解アニメーション、オーバーレイ |
| `games/just-todofuken/js/data.js` | 47 都道府県の正式名と、各 8 件の誤表記データ（`PREFECTURES`） |
| `games/just-todofuken/js/sound.js` | Web Audio によるビープ効果音（`correct` / `wrong` / `clear`） |
| `games/just-todofuken/js/main.js` | 画面遷移・出題生成・判定・タイマー・ベストタイム保存・X 共有 |

### 変更ファイル

- `games/index.html` — ゲームカード「🗾 Just都道府県名！」を先頭に追加し、本数表記を 17 に更新

## 使い方

1. 「スタート！」をタップするとタイマーが動き出し、第 1 問が表示される
2. 9 枚のカードのうち、正しい都道府県名を 1 つタップする
3. 正解すると「正解！」と表示され、次の問題へ進む
4. 不正解のカードはグレーアウトして再タップできなくなり、正解するまで同じ問題が続く（タイマーは止まらない）
5. 5 問すべて正解するとリザルト画面にタイムとベストタイムが表示される
6. 「𝕏 でシェアする」で以下の本文を X.com に投稿できる

```
Just都道府県名！全問正解！12.34秒でした！
https://tokita.net/games/just-todofuken/
```

## 技術的な補足

- **出題**: `pickQuestions()` が 47 都道府県をシャッフルして先頭 5 件を選ぶ（重複なし）。`buildQuestion()` が正解 1 件 + 誤表記 8 件をシャッフルして 9 枚にする
- **誤表記のパターン**: 似た字形の漢字への置換（埼→崎、鳥→島）、都・道・府・県の種別違い（大阪県）、同音別字（石川→石河）、1 文字欠落（神奈県）、隣接文字の入れ替え（奈神川県）、カタカナ混入（山ロ県）
- **データ検証**: `main.js` 初期化時に `validateData()` が各都道府県の誤表記が 8 件以上あるか・重複がないか・実在の都道府県名と一致していないかを確認し、問題があれば `console.warn` で知らせる（動作は止めない）
- **タイマー**: `performance.now()` で計測。HUD は 50ms ごとに 0.1 秒刻みで更新し、リザルトでは小数第 2 位まで表示
- **入力ロック**: 正解/不正解のオーバーレイ表示中は `state.locked` で入力を無視し、連打・二重判定を防ぐ
- **ベストタイム**: `localStorage` のキー `just-todofuken.besttime` に最短タイムを保存。更新時はリザルトに「NEW RECORD!」バッジを表示
- **X 共有**: `window.location.href` から `/index.html` を除いた URL を本文に含め、タップイベント内で `window.open` を呼ぶ（ポップアップブロッカー対策）
- **フォント**: 旧字体・異体字はスマホ標準フォントで表示できない場合があるため、誤表記には常用漢字レベルの文字を中心に使用している
