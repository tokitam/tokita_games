# いろタッチ（早押し反射ゲーム）

対応 issue: #14

## 概要

表示される色名のフォント色と同じ色のパネルをすばやくタップするストループ効果ゲーム。20秒間のスコアアタック形式。

## 実装内容

### ファイル構成

```
games/iro-touch/
├── index.html
├── css/
│   └── style.css   — タイマーバー・パネル・アニメーション
└── js/
    ├── sound.js    — 正解/不正解/ゲームオーバー効果音
    └── main.js     — 問題生成・タイマー・スコア管理・画面遷移
```

## 使い方

- 画面中央に大きく表示される色名のテキストを見る
- テキストの**色（フォント色）**と同じ色のパネルをタップ（文字の意味は関係ない！）
- 正解なら +1点、即次の問題へ
- 不正解はペナルティなし（すぐ次の問題に挑める）
- 20秒で何点取れるかを競う

## 使用する色

あか・あお・みどり・きいろ・むらさき・オレンジ（計6色）

## 技術的な補足

- ストループ効果: 問題生成時に文字の意味とフォント色が必ず異なるよう保証（同一なら再抽選）
- 選択肢4色には必ず正解（フォント色）を含み、残り3色はランダム選択
- `setInterval` で1秒ごとにカウントダウン（`clearInterval` でリセット確実）
- タップ後 200ms の入力ロックで連打防止
- タイマーバーは CSS `width` 変化で視覚表現、残り5秒以下で赤＋シェイクアニメーション
- パネルは CSS Grid 2×2 レイアウト、`touch-action: manipulation` で誤タップ防止
- ローカル確認: ブラウザで `games/iro-touch/index.html` を直接開いてOK
- localStorage: `iro-touch.highscore`
