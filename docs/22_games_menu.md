# games/ メニュー画面

## 概要
`games/index.html` として全ゲームへのリンクを並べたポータルページを追加した。スマホでのタップ操作を最優先にしたカードグリッドレイアウト。

## 実装内容
- **追加ファイル**: `games/index.html`（CSS はインライン `<style>` で完結、JS なし）
- ヘッダーにサイトタイトルとゲーム総本数を表示
- 全 20 ゲームをカードグリッドで表示。カード全体がリンク（絵文字 + ゲーム名）
- 並び順は docs/ 連番の降順（新しいゲームが上）

## 使い方
`/games/` または `games/index.html` を直接開くとメニューが表示される。カードをタップ/クリックすると各ゲームへ遷移する。

## 技術的な補足
- レイアウト: CSS Grid `repeat(auto-fill, minmax(150px, 1fr))`。スマホ（〜399px）では 2 列を強制
- デザイントークンは既存ゲームと同一パレット（`#f0f4ff` 背景 / `#6c63ff` アクセント / `#ff6b9d` サブアクセント）
- `viewport-fit=cover` と `-webkit-tap-highlight-color: transparent` を設定
- ゲーム追加時はカードを手動で追記する（静的構成のため自動生成なし）
