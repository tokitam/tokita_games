# カラフルクラッシュ（ブロック崩し）

対応 issue: #9

## 概要

Canvas を使ったブロック崩しゲーム。指またはマウスのドラッグでパドルを操作し、カラフルなブロックをボールで全て壊すとステージクリア。4種類のアイテムドロップとパーティクルエフェクトで賑やかに仕上げた。

## 実装内容

### ファイル構成

```
games/colorful-crash/
├── index.html
├── css/
│   └── style.css
└── js/
    ├── sound.js    — Web Audio API 効果音（6種）
    ├── levels.js   — ステージ定義（ブロック配置・色・強度）
    ├── game.js     — ゲームループ・物理・AABB衝突・アイテム管理
    └── main.js     — Canvas描画・入力処理・画面遷移
```

## 使い方

- マウス移動 / タッチドラッグでパドルを左右に操作
- ボールが落ちたら残機 -1（初期 3）、全部落ちたらゲームオーバー
- 全ブロックを壊すとステージクリア（自動で次レベルへ）
- アイテム（落下してくる絵文字）をパドルで受け取ると効果発動

| アイテム | 効果 |
|---|---|
| 🔴 | ボール増殖（現在のボールが+2個） |
| 🟢 | パドル拡大（15秒、緑色に変化） |
| 🔵 | ボールスロー（10秒） |
| ⭐ | 残機+1（最大5） |

## 技術的な補足

- 衝突判定: AABB（軸平行境界ボックス）でボール対ブロック・パドル・壁を処理
- パドル反射角: ボールがパドルに当たった位置（中央=まっすぐ、端=最大60度）で反射角を制御
- ボール速度上限: 11px/frame（スマホで視認できる速さ）
- 硬いブロック（hp=2〜3）はステージ2以降登場、被弾でひびアニメーション
- アイテム落下中は点滅して「取れる！」感を演出
- ブロック破壊時に7粒パーティクル散布（18〜26フレームで消える）
- 画面上部（70%以上）タップ or Pキーでポーズ
- ローカル確認: ブラウザで `games/colorful-crash/index.html` を直接開いてOK
- localStorage: `colorful-crash.highscore`
