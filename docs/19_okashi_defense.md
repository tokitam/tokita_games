# お菓子ディフェンス

## 概要
BabylonJS を使ったお菓子の国の3Dタワーディフェンス。S字カーブの道を歩いてくるマカロン軍団を、タップで設置するお菓子砲台で10ウェーブ迎え撃つ。

## 実装内容
- `games/okashi-defense/index.html` — SPA（タイトル・ゲーム・クリア/ゲームオーバー）
- `games/okashi-defense/css/style.css` — HUD、砲台選択ポップアップ、ライフ・シュガー表示
- `games/okashi-defense/js/sound.js` — Web Audio API で攻撃/爆発/死亡/ゲームオーバー音
- `games/okashi-defense/js/data.js` — 8×10 グリッド、ウェイポイント、砲台/敵/ウェーブ定義
- `games/okashi-defense/js/game.js` — ゲーム進行、ターゲティング、弾、経済（シュガー）
- `games/okashi-defense/js/main.js` — BabylonJS シーン、カメラ、メッシュ、入力

## 使い方
1. タップでゲーム開始
2. 空きマスをタップ → 砲台選択 → 種類を選んで設置（シュガーを消費）
3. 既存砲台をタップ → 強化メニュー（最大3段階）
4. 敵を倒しながら10ウェーブを守り切るとクリア
5. ライフ10がゼロになるとゲームオーバー

## 技術的な補足
- グリッド: `0`=設置可, `1`=道, `2`=装飾。ウェイポイント配列で敵の経路を管理
- 敵の移動: ウェイポイント間を距離ベースの `t` で線形補間。減速は `t` の進みに係数を掛ける
- 砲台ターゲティング: 毎フレーム射程内で最も進んでいる敵を選択、クールダウン管理
- チョコ爆弾: 着弾点から半径1.5の全敵にダメージ＋爆発パーティクル
- HPバー: 頭上の Plane（ビルボードモード）でリアルタイム更新
- スコア: 倒した敵の得点合計＋残ライフ×50。localStorage でハイスコア保存
