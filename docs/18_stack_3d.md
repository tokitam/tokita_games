# スタック3D

## 概要
BabylonJS を使った3Dスタックゲーム。左右に往復するブロックをタップで止めて積み上げる。ずれた部分は切り落とされ、完全にずれたらゲームオーバー。

## 実装内容
- `games/stack-3d/index.html` — タイトル・ゲームのSPA
- `games/stack-3d/css/style.css` — シンプルなダーク背景。スコアと段数を上部に表示
- `games/stack-3d/js/sound.js` — タップ・パーフェクト・ゲームオーバー効果音
- `games/stack-3d/js/game.js` — 切断ロジック（区間重なり計算）・移動制御・スコア
- `games/stack-3d/js/main.js` — BabylonJSシーン・ブロックメッシュ・カメラ追従・入力・演出

## 使い方
1. タップでゲーム開始
2. タップでブロックを止める
3. 積み上げるほどスコアが増加、速くなる
4. 完全にずれたらゲームオーバー

## 技術的な補足
- 切断ロジック: 重なり区間を計算し、残る部分・落ちる部分をそれぞれ `CreateBox` で生成
- パーフェクト判定: ずれが辺の5%以内（サイズ×0.05）でブロック縮小なし＋キラッと演出
- 3連続パーフェクトでブロック幅 +0.25 回復（初期サイズ上限）
- 色は HSL で段ごとに8°ずつ回転してグラデーション
- カメラは `Lerp` で最上段＋2ユニットを追従、ゲームオーバー時はズームアウト
- ハイスコアは `localStorage['stack-3d.highscore']` に保存
