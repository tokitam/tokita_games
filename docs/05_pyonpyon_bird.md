# ぴょんぴょんバード（フラッピー系）

対応 issue: #10

## 概要

タップ/クリックするたびに鳥が上昇し、左から流れてくる土管の隙間をくぐり続けるフラッピーバード系ゲーム。Canvas + Vanilla JS で実装し、スコアを localStorage に保存する。

## 実装内容

### ファイル構成

```
games/pyonpyon-bird/
├── index.html
├── css/
│   └── style.css       — オーバーレイ・ボタンスタイル
└── js/
    ├── sound.js        — Web Audio API 効果音（3種）
    └── game.js         — ゲーム全体（物理・描画・状態管理）
```

## 使い方

- タップ/クリックで鳥が上昇
- 重力で常に落下するため連続タップが必要
- 土管の隙間を通過するたびに +1点
- 土管または画面上端・下端に接触でゲームオーバー

## 技術的な補足

- ゲーム状態: `waiting` → `playing` → `dead` → `over` のステートマシン
- 最初のタップがゲーム開始兼ジャンプを兼用（UX簡略化）
- 土管はプールパターンで管理。画面外に出たら配列から削除
- 重力 0.38 px/frame²、タップ時上昇速度 -7 px/frame
- スコア10通過ごとに速度 +0.3（最大 5.5）、スコア20ごとに隙間 -5px（最小 120px）
- 当たり判定は鳥の半径 -4px（ゲーム的な「遊び」）
- `devicePixelRatio` 対応でレティナ画面もクッキリ描画
- 死亡後40フレームの落下アニメーション後にゲームオーバー画面を表示
- ローカル確認: ブラウザで `games/pyonpyon-bird/index.html` を直接開いてOK
- localStorage: `pyonpyon-bird.highscore`
